# 图片清单与风格规范

本文档说明全站图片的**补图位置、内容建议与风格要求**。当前页面已接入一组项目自有的 WebP 视觉资产；未覆盖的路线仍保留安全占位框，后续补图时只需扩展 `src/data/media.js`，不必改动页面组件。

---

## 一、统一风格规范（樱花粉奶萌可爱风）

| 维度 | 要求 |
|---|---|
| **主色调** | 樱花粉（#f45d87 系）与奶油白为主，薄荷绿 / 天蓝 / 柠檬黄作点缀，避免大面积冷色或纯黑白 |
| **光线** | 柔和自然光、低对比、暖调，避免强逆光或死黑 |
| **氛围** | 治愈、清新、轻盈、可爱；避免暗沉、冷峻、压抑的画面 |
| **构图** | 主体突出、留白充足，适合卡片与封面裁切 |
| **版权** | 一律使用免版权素材（Unsplash / Pexels / 日本政府观光局 JNTO 开放素材）或自摄，不得使用原书配图 |
| **命名** | 统一放 `public/images/` 下，文件名用数据 id，如 `tokyo-classic.jpg` |

**推荐尺寸**：
- 路线卡片封面：横版 **16:9**，≥ 1280×720
- 路线详情封面：横版 **21:9**，≥ 1920×820
- 地区卡：横版 **16:9**，≥ 1280×720

## 四、Top25 体验缩略图（可选）

Top25 目前以 emoji 为主视觉，**不强制配图**。若后续想提升质感，可为每个体验补一张小缩略图（`image` 字段），建议 1:1 方形，内容直接对应体验本身（如「温泉」→ 露天风吕、「赏樱」→ 樱花树下）。可复用对应路线的封面图以降低工作量。

## 五、技术说明

1. 原始数据仍保留 `image` 字段；集中回退映射位于 `src/data/media.js`，优先使用数据自身的图片路径。
2. 填图方式：`image: '/images/tokyo-classic.webp'`（放 `public/images/` 下，构建后原样拷贝）。
3. 组件 `src/components/ImgSlot.vue` 负责渲染：`image` 为空时显示占位框（虚线框 + 提示文案），非空时渲染 `<img loading="lazy">`。
4. 新增图片时优先使用 WebP，保留横版构图和主体留白，避免文字、Logo、水印与可识别私人肖像。
