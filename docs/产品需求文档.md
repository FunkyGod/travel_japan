## 1. 产品概述

### 1.1 背景
市面上日本旅行攻略信息碎片化严重（散落在社交平台、视频、App），缺少一份**结构完整、可爱治愈、离线可用、覆盖全国**的中文旅行指南手册。本产品以经典旅行指南的书本结构为骨架，用轻量 Web 形态承载，面向中文旅行者。

### 1.2 产品定位
一款「可爱风的中文日本自助游手册」——既有旅行指南的**深度与体系**，又有 App 的**检索、收藏、预算换算**能力。

### 1.3 目标用户画像

| 画像 | 特征 | 核心诉求 |
| --- | --- | --- |
| 首次访日者 | 没去过 / 只去过东京 | 快速上手、经典路线、语言障碍、预算 |
| 深度玩家 | 二刷以上、喜欢徒步/温泉/艺术 | 冷门地区、主题线路、文化背景 |
| 亲子家庭 | 带娃出行 | 儿童友好、节奏舒缓、安全提示 |
| 预算敏感者 | 学生 / 背包客 | 省钱妙计、通票怎么算、平价吃住 |
| 行程规划者 | 做攻略的人 | 逐日行程、交通衔接、收藏导出 |

### 1.4 价值主张
「**一套可爱手册，从零到出发**」——路线给方案、地区给广度、文化给厚度、贴士给安全感、收藏给计划性。

---

## 2. 产品目标与成功指标

### 2.1 目标
1. 内容覆盖日本 **11 个地区**、**18 条精品路线**、**10 个文化主题**、**4 大专题**。
2. 移动端体验流畅，首屏可交互时间 < 3s（懒加载 + PWA）。
3. 站内内容形成交叉链接网络，人均浏览页面数提升。

### 2.2 成功指标（建议）
- 单次会话浏览 ≥ 3 页；收藏功能使用率 ≥ 15%。
- 核心页面 Lighthouse 性能 / 无障碍 / SEO 三项 ≥ 90。
- 深度路线（如高野山、濑户内）的访问转化不显著低于经典线。

## 4. 功能需求

### 4.1 内容数据模型（数据结构约定）

**路线（route）** 字段：
```
id, regionSlug, image, emoji, title, subtitle, days, region,
tags[], season, budget[lo,hi], description,
stay, eat, highlights[], itinerary[{day,title,detail}],
transport[], tips[],
（P1-3 新增）costs[{type,low,high}]（住宿/餐饮/交通/门票四档）,
（P1-3 新增）spots[{name, hours, fee}]（亮点开放时间与门票）
```

**地区（region）** 字段：`slug, emoji, name, image, desc, highlights[]`，并新增 `speedView{season,budget,audience}` 供速览表使用。

**文化主题（culture）** 字段：`id, emoji, title, summary, sections[{title, body}]`。

### 4.2 核心功能清单

| 模块 | 功能 | 优先级 |
| --- | --- | --- |
| 路线 | 列表筛选（地区/标签/搜索）、详情、相关路线、收藏 | P0（已有） |
| 地区 | 地区卡片、地区→路线筛选、地区速览对比表 | P1 |
| 季节 | 12 个月日历、月份→当季路线/祭典联动 | P0（已有）+ 加深 |
| 温泉 | 礼仪四步、名泉、泉质科普、小词典、纹身提醒 | P0（已有） |
| 美食 | 地区美食、餐馆类型、常见菜单、点餐/素食 | P1 |
| 文化 | 10 主题原创精简解读 | P0 |
| 交通 | 交通方式百科 + 通票决策树 | P0 |
| 专题 | 滑雪/亲子/徒步/省钱 四页 | P1 |
| 预算 | 双币显示（¥/￥）、三档预算、汇率配置 | P0（已有）+ 汇率实时化 |
| 收藏 | 增删收藏、列表、导出 Markdown | P2 |
| 搜索 | 全局全文搜索（含新增内容） | P0（已有） |
| 行程 | 行程规划器（拖拽拼装 + 导出） | P2 |
| 地图 | 路线点位地图标注 | P2 |

### 4.3 交互细节

- **双币显示**：所有价格以日元为准，副显人民币（`RATE = 23.6` 为离线回退基准）。实际支付前以实时汇率为准。
- **收藏**：localStorage 持久化，key `japan-guide:favorites`，跨页面共享响应式状态。
- **搜索**：跨 路线/地区/体验/美食/温泉/季节/贴士（后续纳入 文化/交通/专题）。
- **打印**：路线详情与收藏支持打印友好排版（出行前纸质备用）。

## 5. 内容需求

### 5.1 内容体系（对标原书四大部分）

| 版块 | 内容 | 来源章节 |
| --- | --- | --- |
| 计划你的行程 | Top25、路线、季节、专题（滑雪/亲子/徒步/省钱） | 计划你的行程 |
| 在路上 | 11 地区 + 18 路线（含逐日行程） | 在路上 |
| 了解日本 | 历史/日本人/料理/艺术/建筑/住宿/体育/艺伎/环境 | 了解日本 |
| 生存指南 | 出行指南、交通指南、语言 | 生存指南 |

### 5.2 内容质量要求
1. **原创重写**：仅引用客观事实（地名、价格、开放时间、数字），禁止逐字搬运原书表述。
2. **事实标注**：价格/时间类信息标注「参考价，需实时确认」，避免过时误导。
3. **导游视角**：每条路线必须回答「住哪、吃什么、怎么去、多少钱、什么时候去、备选方案」。
4. **可爱风格化**：文案在准确前提下可轻快俏皮，与视觉风格一致。

### 5.3 版权与合规
- 不使用来源出版物的商标或名称，不在源码 / 产物中引用 OCR 文本。
- 图片版权：使用项目自有 imagegen WebP 资产与可替换回退映射，不使用原书配图；未覆盖位置保留占位组件。

## 6. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 路由级懒加载；首屏 JS < 200KB；Lighthouse ≥ 90 |
| SEO | History 路由 + 每页动态 title/description/OG 标签；新增页面补 meta |
| 响应式 | 移动优先，网格断点 700px/900px 收缩为单列 |
| 无障碍 | 语义化标签、`prefers-reduced-motion`、焦点态、对比度 |
| 离线 | PWA：manifest + Service Worker（运行时缓存）+ SVG 图标 |
| 打印 | 路线/收藏页打印样式（隐藏导航与装饰） |
| 国际化 | 中文为主，日文短语保留原文 + 罗马音（语言章节） |

## 7. 设计规范（可爱风）

- **主色**：樱花粉（`--sakura-*` 色阶）+ 奶油白（`--milk`）+ 柠檬黄（`--lemon`）点缀。
- **氛围**：樱花飘落动画（`SakuraPetals`，尊重 `prefers-reduced-motion`）、圆角卡片、柔和阴影。
- **组件**：PageHero（页头）、SectionHead（分区头）、RouteCard、ImgSlot（图片占位）、FavButton、SiteNav、SiteFooter。
- **图片占位**：补图前用虚线占位 + emoji + 文案提示，补图后无缝替换为 `<img>`（见 ImgSlot.vue）。

## 8. 数据与汇率

- 汇率基准：`1 CNY ≈ 23.6 JPY`（`RATE = 23.6`，仅作离线回退估算）。
- 双币工具：`yenToCny` / `formatYen` / `formatYenRange`（src/utils/format.js）。
- 后续：汇率改为可配置，预留实时接口，离线回退基准值。
