# 日本旅游指南网站 · 改进建议

> 对标依据：用户提供的中文日本旅行指南 PDF（2016 年版本）全书结构
> 视角：资深导游 + 深度玩家 + 产品经理
> 日期：2026-08-14

---

## 一、总体评估

### 现状盘点

| 维度 | 现状 |
| --- | --- |
| 页面 | 9 个：首页 / 路线列表 / 路线详情 / 季节日历 / 温泉 / 美食 / 实用贴士 / 搜索 / 收藏 |
| 路线 | 15 条精品深度路线（含逐日行程、交通、住宿建议、必吃推荐、双币预算） |
| 地区 | 9 个地区板块（东京 / 富士山周边 / 阿尔卑斯与中部 / 京都 / 关西 / 广岛与西部 / 北海道 / 九州 / 冲绳） |
| 内容库 | Top25 体验 25 项、温泉 9 处＋泉质＋礼仪、美食 13 项、季节 12 个月、贴士 9 类＋预算三档＋应急日语 |
| 工程 | Vue3 + Vite、History 路由、路由级懒加载、SEO 动态 meta、PWA（SW + manifest）、localStorage 收藏、响应式 + 打印样式 + 无障碍 |

### 优势（已经做得好的）

1. **路线即产品**：15 条路线把「逐日行程 + 交通 + 住 + 吃 + 预算」打包，是比纯攻略更实用的形态，符合导游思维。
2. **工程底座扎实**：SEO、PWA、懒加载、双币换算、收藏系统都是正确且完整的功能，而非半成品。
3. **版权边界清晰**：全部原创重写，价格数字属客观事实，无逐字搬运风险。

### 核心短板（一句话）

**覆盖了「怎么走」，但还没覆盖「为什么值得去」和「去了看什么」——即原书占比最大的两块：地区深度与文化解读，恰恰是当前网站最薄弱的环节。**

### 2.3 了解日本（原书 10 个文化主题）

原书这一整章（今日日本 / 历史 / 日本人 / 日本料理 / 艺术 / 建筑 / 传统日式住宿 / 体育 / 鲜活的艺术：艺伎 / 环境）**网站上没有任何对应内容**。

这是一块被低估的价值：原书把「历史 / 文化解读」作为核心卖点印在封面。一个没有文化背景的旅行网站，等于「给你路线却不告诉你为什么值得去」。这是资深导游视角下最该补的一块。

## 三、分级改进建议

### P0 —— 内容硬缺口（补上「为什么值得去」）

**P0-1 补齐「东北」地区（新增 1 地区 + 2 路线）**
- 新增地区 `tohoku`（本州北部）：仙台、松岛、奥入濑溪流、山形藏王、会津若松、田泽湖、乳穗温泉。
- 新增路线示例：`东北奥入濑·藏王 5 日`（仙台→松岛→奥入濑溪流→藏王温泉）、`东北环线 7 日`（青森→十和田湖→角馆→山形→会津若松）。
- 理由：东北有「松岛三景」「奥入濑溪流」「藏王树冰」三大世界级资源，且滑雪资源不输北海道，是本书体量第三大的地区。

**P0-2 补齐「四国」地区（新增 1 地区 + 1~2 路线）**
- 新增地区 `shikoku`：松山（道后温泉）、高松（栗林公园、赞岐乌冬）、鸣门涡潮、祖谷溪、四万十川。
- 新增路线示例：`四国环线 6 日`（高松→德岛鸣门→祖谷→松山道后温泉→四万十川）。
- 理由：道后温泉是日本最古老温泉之一（已出现在 onsen 列表却无落地路线），四万十川被称为「日本最后的清流」。

**P0-3 新增「了解日本」文化专栏（1 个页面，10 个主题）**
- 新增 `/culture` 页面，覆盖原书 10 主题的原创精简版：今日日本、历史脉络、日本人（礼仪/敬语）、日本料理（含「和当地人吃喝」）、艺术（浮世绘/花道/茶道）、建筑（神社/寺院/城堡）、传统日式住宿（旅馆入住指南）、体育（相扑/棒球）、艺伎文化、环境。
- 价值：让「吃住行」之上有「文化钩子」，显著提升内容的可读性与分享性，也与「可爱风」反差形成记忆点。

**P0-4 新增「交通指南」页（`/transport`）**
- 系统化：铁路（JR / 私铁 / 新干线 / 特急 / 指定席 / 通票）、巴士（高速/夜行/市内）、自驾（租车/驾照/冬季雪胎）、国内航班、渡轮。
- 附「通票决策树」：先算总车费再决定买不买 Pass（现有 tips 已有雏形，可独立成页并可视化）。

### P1 —— 专题与深度

**P1-1 新增 4 个专题页**（对标原书「特别呈现」）：
- `/ski` 滑雪专题：北海道二世古、长野野泽/白马、新潟苗场，含季节、装备、租赁、雪场难度分级。
- `/family` 亲子旅行：东京迪士尼、大阪环球影城、奈良喂鹿、冲绳水族馆，含适合年龄段。
- `/hiking` 徒步专题：阿尔卑斯徒步、熊野古道、屋久岛、妻笼–马笼，含难度分级与装备清单。
- `/budget` 省钱妙计：住宿省钱（胶囊/青旅/民宿）、交通（夜行巴士/青春18）、餐饮（超市便当/百元店/立食）、门票（联票/免费观景台）。

**P1-2 美食页深化**：补「餐馆类型」（居酒屋/回转寿司/立食/食堂/料亭/连锁）、「常见菜单」（前菜/刺身/烤物/煮物/主食的日文对照）、「点餐与素食/过敏说明」。现有 13 项美食仅覆盖「吃什么」，未覆盖「怎么点」。

**P1-3 路线详情增强**（导游视角的实用细节）：
- 预算明细：把 `budget` 拆成 住宿/餐饮/交通/门票 四项逐日估算（而非单一口径区间）。
- 门票与开放时间：每处亮点补参考价与闭馆日。
- 最佳拍照点 / 时间：如「河口湖富士倒影清晨最佳」「清水寺傍晚人少」。
- 备选方案：雨天 / 旺季拥挤时的 Plan B。

**P1-4 内容交叉链接**：路线详情页自动关联同地区「美食 / 温泉 / 贴士 / 季节」，形成内容网络，提升站内停留与 SEO 内链。

### P2 —— 体验与增长

1. **行程规划器**：用户把多条路线的「天」拖进自定义行程，导出清单（本地存储 + 打印）。
2. **地图集成**：路线详情嵌入静态地图 / 点位标注（可选 Leaflet + OSM，避免依赖海外 API）。
3. **汇率实时化**：`RATE = 23.6` 目前写死，改为配置项 + 预留 API 接口（离线时回退到基准值）。
4. **收藏分享/导出**：收藏列表支持一键导出 Markdown / 图片分享。
5. **「如果你喜欢」推荐**：基于标签（温泉/徒步/美食/艺术/亲子）的个性化推荐入口。
6. **地区速览对比表**：11 地区 × 维度（最佳季节/预算/适合人群/亮点）的速查表。
